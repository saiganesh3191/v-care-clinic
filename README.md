# V Care Clinic

Separate Next.js website based on the client reference. Run `npm install` and `npm run dev`, then visit http://localhost:3001. `npm run build` produces the static site in `out`.

## Content review

Clinic details and service categories are transcribed from the supplied reference and need client confirmation before public launch. Logos are text-based approximations. No unverified review counts, star ratings, patient testimonials, or patient totals are presented as facts. The appointment form prepares a WhatsApp message; nothing is stored and reception must confirm appointments. Confirm that the clinic phone supports WhatsApp before launch.

Doctor portrait and qualifications source: https://primehighcarehospitals.com/doctors/ . Portrait: https://primehighcarehospitals.com/wp-content/uploads/2026/07/fa198714-8c44-4a0d-9d96-bbed136f2777-e1784540733877.jpg . Client should confirm permission to reuse the hospital portrait.
